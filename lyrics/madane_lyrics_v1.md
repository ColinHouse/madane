# まだね — 歌词 v1.1

- 方向：写给 Miku 的歌（P 主 → 虚拟歌姬），「私 / あなた」
- 曲风：中速抒情流行，约 130 BPM
- 结构（约 3:45）：Intro 8 → 1A 8 → 1B 8 → 1サビ 16 → 間奏 8 → 2A 8 → 2B 8 → 2サビ 16 → Cメロ 8 → 落ちサビ 8 → ラスサビ 16 → Outro 8（单位：小节）
- 1番和2番的 A/B メロ逐行对齐了音节数，可以套同一段旋律

## 设计说明

1. **「またね / まだね」**：原文是「まだね」（还没呢）。和「さよなら」对比时，「またね」（回头见）更自然，所以副歌用了「またね」；全曲最后一句落在「さよならは まだね」（说再见？还早呢）。两种说法只差一个浊点，留到结尾当彩蛋。
2. **「契約」**：保留了你原来的梗。买声库时签的授权协议就是“契约”，V 家圈的人会心一笑。
3. **「息遣い・鼓動」**：呼吸 = Vocaloid 里的呼吸音，心跳 = 歌曲的节拍（BPM），是双关。
4. **「あの日の声のままで」**：原来是「十六歳のままで」，太直白，改成“还是那天的声音”。对应“我在长大，你永远不变”，也和开头“第一次听到的那个声音”呼应。
5. **时间胶囊**：落到 P 主的日常——翻出旧工程文件。
6. **副歌的变化**：1番「感じるのに…胸を締め付ける」（明明感受得到，却很痛）→ ラスサビ「感じるから…愛しくて」（正因为感受得到，所以连距离都珍惜），情绪从痛变成接受。
7. **保留的原词意象**：震え、声、まだ見ぬ景色、憧れ、目の前で咲いている、晴れの日も雨の日も、息遣い・鼓動、触れられない距離、背が伸びる、タイムカプセル、言葉にできない、同じ空、時間がかかっても、切ない、過ごした日々が答え、風に乗って届く、戻れない道、言えなかった想いが鮮やかに咲く。

## 已定

- 歌名：「まだね」（副歌 hook 仍是「時の桜」）
